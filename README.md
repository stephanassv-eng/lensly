# Lensly – Discover the World

Lensly is a simple image discovery application where users can search for topics and explore related images. It is designed to make visual exploration easy through a clean and responsive interface.

## Design Decisions

- I chose a warm cream and orange colour theme to create a friendly and welcoming experience.
- I added category suggestion chips so users can quickly explore popular topics.
- I used CSS Grid with `auto-fill` and `minmax()` to make the results layout responsive across different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox

## Project Structure

- `index.html` – Page structure
- `styles.css` – Styling and responsive layout
- `script.js` – JavaScript scaffold for future search functionality
